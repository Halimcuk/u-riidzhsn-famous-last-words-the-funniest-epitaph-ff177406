This entry, "The Punctual Reaper", is a one-line epitaph of famous last words for the make.fun bounty "Famous Last Words: The Funniest Epitaph": a deterministic Node program that writes a single deadpan line of dying speech to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set), with no trailing newline, treating a lifetime of waiting as a queue and letting death turn out to be the one thing that ever showed up on time.

## Run it

```sh
node main.ts
```
